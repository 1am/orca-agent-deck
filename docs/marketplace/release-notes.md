First release on the Marketplace.

- Pane keys show each Orca pane's state (working, needs input, awaiting reply, done, error, offline) and the agent's icon. Press a key to focus that pane.
- The Attention key counts the panes that need you and takes you to the most urgent one.
- The Status key shows setup checks and tells you when the Orca plugin is missing.
- Map keys from the Agent Deck panel in Orca: hold a key, or press Cmd+Alt+K (Ctrl+Alt+K on Windows).
- Works with local panes, SSH hosts and tmux.
- Requires Orca 1.4.248 or newer and the companion Orca plugin.
